## 一句话定位

- 项目 ID：`guofeng-card-rpg`
- 游戏名称：云阙列传
- 品类：国风卡牌 RPG
- 核心体验（一句话）：在深蓝鎏金的云阙世界中抽卡集将、编队征战，并以轻度养成维持日常回流。

## 目标用户与卖点

- 目标用户：喜欢国风卡牌、轻度养成与短局战斗的移动端玩家
- 核心卖点（3 条以内）：
  1. 雅致国风视觉：深蓝、鎏金、白玉，区别于大红促销页游风
  2. 清晰枢纽：主城三秒识别资源与去向
  3. 短循环闭环：编队 → 战斗 → 抽卡/商店补给 → 回主城
- 竞品差异（不抄袭，只比品类体验）：强调沉静贵气与可读信息层级，而非堆叠霓虹特效与密集运营角标

## 核心循环

```text
登录/回流 → 主城认识资源 → 编队准备 → 战斗挑战 → 结算成长 → 抽卡/商店补给 → 回流
```

| 环节 | 玩家目标 | 主要界面 | 成功标准 |
|---|---|---|---|
| 回流 | 快速进入下一动作 | `home` | 三秒识别主操作与底栏 |
| 准备 | 配齐前后排并确认战力 | `formation` / `bag` | 可保存阵容；缺员有提示 |
| 核心玩法 | 完成波次战斗 | `battle` | HP/灵力/技能可读，可自动与倍速 |
| 结算成长 | 获得卡牌或养成材料 | `gacha` / 结算回流主城 | 抽卡消耗与结果反馈清晰 |
| 商业补给 | 购买道具与资源 | `shop` / `bag` | 货币不足可导向获取路径 |

## 系统清单

| 系统 ID | 名称 | 优先级 | 依赖 | 说明 |
|---|---|---|---|---|
| home | 主城 | must-have | wallet, profile | 枢纽与风格基准页 |
| formation | 编队 | must-have | roster | 前后排站位 |
| battle | 战斗 HUD | must-have | formation | 短局卡牌战斗 |
| gacha | 抽卡 | must-have | wallet | 核心获取 |
| shop | 商店 | must-have | wallet | 补给与礼包 |
| bag | 背包 | must-have | inventory | 道具使用与出售 |
| guild | 公会 | optional | social | 本迭代不生图 |
| rank | 排行榜 | optional | battle | 本迭代不生图 |
| event | 活动中心 | optional | home | 本迭代仅主城 banner 占位 |

## 资源与经济（策划层）

- 软通货：铜钱/银两（日常消耗）
- 硬通货：玉锭（抽卡与礼包）
- 体力/行动力：体力值，上限可见，可恢复或购买
- 掉落与产出节奏（概述，不写服务端公式）：战斗与活动产材料；抽卡产卡牌与碎片；商店兑换补给
- 禁止在本阶段假装已完成真实支付与服务端校验

## 进度与养成

- 角色/卡牌成长轴：等级、星级、阵营羁绊（UI 展示，数值后置）
- 关卡/挑战进度轴：波次战斗 + 主城活动入口
- 日常/周常回流钩子：主城活动 banner、邮件红点、体力回满

## 叙事与世界观（UI 所需最小集）

- 时代/气质：云阙夜色、庭院月色、雅致仙侠而非血腥战场
- 势力或阵营（如有）：蜀/魏/吴/群等阵营色仅作识别，不绑定真实历史 IP
- UI 文案语气：典雅、简短、可读；标题可匾额感，正文清晰

## 风险与约束

- 版权：禁止复刻受保护国风 IP 角色与商标
- 题材敏感点：避免过度宗教符号与敏感历史影射
- 技术/美术成本：页面先 9:16 视觉；组件无字切图；生产前裁切 1080×1920
