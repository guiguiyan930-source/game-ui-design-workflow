# UI 项目规格

## 项目定位

- 项目 ID：`guofeng-card-rpg`
- 游戏名称：云阙列传
- 游戏类型：国风卡牌 RPG
- 核心玩法：抽卡集卡、编队挑战、养成成长、商店补给
- 目标平台：移动端竖屏
- 画面比例：9:16，1080×1920
- 目标用户：喜欢国风卡牌与轻度养成的玩家
- 文案语言：zh-CN

## 输入资料

- 参考图片：无用户原图；采用深蓝鎏金国风卡牌视觉规范
- 现有页面：无
- 品牌或版权限制：不复刻受保护 IP；只使用原创国风纹样与角色气质

## 用户故事

### US-01

作为一名玩家，我希望从主城一眼看到角色、资源和去向，从而快速进入抽卡、编队或商店。

验收场景：

1. Given 进入主城，When 浏览首屏，Then 三秒内可识别主操作与底部导航。
2. Given 资源不足，When 点击抽卡或购买，Then 有清晰货币反馈入口。

## 范围

### 包含

- 深蓝鎏金国风视觉契约
- 主城、编队、抽卡、商店、背包、战斗 HUD 屏幕地图
- 主城原型视觉与核心页面提示词
- 组件雪碧图、语义切图、ZIP 包

### 不包含

- 服务端经济数值与真实支付
- 原生引擎工程导入
- 自动视觉检测与自动去字修复

## 视觉目标

- 情绪：雅致、沉静、贵气
- 风格关键词：深蓝、鎏金、白玉、云纹、卷轴、窗棂
- 识别性目标：鎏金主按钮与玉简导航可跨页复用
- 可读性目标：中文短文案清晰，资源数字高对比

## 页面范围

- 首个生成页面：`home`
- 必须延展的系统：编队、抽卡、商店、背包、战斗
- 可选系统：公会、排行榜、活动中心
