# UI 研究记录

## 研究范围

- 项目 ID：`guofeng-card-rpg`
- 分析对象：国风卡牌 RPG 通用界面模式与深蓝鎏金视觉规范
- 研究目标：建立可跨页复用的主城—养成—商业闭环视觉系统

## 参考图视觉抽象

- 色彩与对比：深蓝主面、鎏金描边、米白文字、墨色次级层次
- 材质与纹理：白玉、磨砂金、绢布、窗棂、云纹暗纹
- 光源与阴影：左上柔光，薄金色边缘高光
- 圆角、描边与厚度：卡片 16–24px，细金边 2–4px
- 构图密度：中等，顶栏资源清晰，中部主内容，底部导航稳定
- 图标视角：正视、细描边、统一透视
- 字体气质：匾额标题 + 清晰正文；生图优先短中文或后期排版

## 可复用模式

- 导航模式：底部五入口 + 顶栏货币
- 卡片模式：深蓝半透明玉石卡 + 鎏金稀有度边
- 反馈模式：主按钮按下加深、选中鎏金辉光
- 信息层级：资源 > 主视觉/主操作 > 次级入口 > 装饰

## 玩家旅程与核心循环

1. 首次进入：主城认识资源与导航
2. 准备：编队与背包整理
3. 核心玩法：战斗挑战
4. 结算与成长：抽卡、升级、商店补给
5. 日常回流：任务与活动回流主城

## 风险与约束

- 版权与品牌：禁止复刻既有国风 IP 角色与商标
- 文字生成：页面可用短中文；组件雪碧图必须无文字
- 平台安全区：顶部 48、底部 120，避免贴边
- 复杂度与开发成本：先交付主城与组件包，再按需 Atlas 导出

## 决策

- 采用：深蓝鎏金白玉体系、9:16 竖屏、主城为基准页
- 拒绝：大红促销风、赛博霓虹、欧美卡通主色
- 原因：与国风卡牌气质一致，便于跨页复用
