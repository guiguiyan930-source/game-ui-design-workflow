# 战斗 HUD

## 页面定位

回合制对战中的站位、血条与技能栏。

## 视觉约束

特效不淹 UI，冷色技能光可点缀。

## 布局与组件

- 顶部：波次与战力
- 中部：双方站位战场
- 底部：技能栏、自动、加速

## 状态

default / auto

## 图像生成提示词

Chinese-style card RPG battle HUD, mobile portrait 9:16, deep blue UI overlays, clear HP and energy bars, skill buttons at bottom, battlefield with card characters, restrained skill glow, readable combat UI mockup.

## 反向限制

不要 UI 被特效淹没，不要霓虹激光，不要文字乱码。
