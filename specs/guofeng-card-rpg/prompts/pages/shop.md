# 商店

## 页面定位

分类浏览商品并购买养成材料。

## 视觉约束

加强鎏金点缀但禁止整页大红促销风。

## 布局与组件

- 顶部：商店标题与货币栏
- 中部：左侧分类页签、中央商品卡网格
- 底部：刷新入口

## 状态

default / sold-out

## 图像生成提示词

Chinese-style card RPG shop UI, mobile portrait 9:16, deep blue panels, gilded wood and jade product cards, left category tabs, top currency bar, green-gold purchase buttons without baked long text, short Chinese labels, elegant marketplace, polished game UI mockup.

## 反向限制

不要大红促销贴纸风，不要文字乱码，不要欧美卡通主色。
