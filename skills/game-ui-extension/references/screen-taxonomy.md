# Screen Taxonomy

按项目适配选择，不要默认全量加入。

## Entry

- splash, login, announcement, server-select
- character-create, opening-story, tutorial-overlay

## Core

- home, quest, preparation, stage-select
- battle-hud, pause, fail-revive, settlement

## Growth

- inventory, character, equipment, skills
- ascension, companion, achievement, codex

## Economy

- shop, gacha, battle-pass, subscription
- currency-exchange, ad-reward

## Live Ops

- sign-in, daily-weekly, event-hub
- limited-challenge, seasonal, returner

## Social

- friends, guild, guild-activity, chat
- mail, player-profile

## Competition

- pvp-lobby, matchmaking, leaderboard
- match-history, season-summary, tournament

## Strategy

- formation, deck-builder, loadout
- talent-planner, ai-tactics

## Expression

- wardrobe, housing, photo-mode
- replay, user-content

## Support

- settings, controls, accessibility
- account, customer-support, redeem-code

## Selection questions

For each candidate:

1. Which player-loop transition needs it?
2. What is the primary action?
3. Is it required for launch, genre depth, or optional retention?
4. Can it be merged into another page without hiding a high-frequency action?
5. Which empty, locked, expired, network, and insufficient-resource states apply?
