# 隐私、版权与安全

## 不要提交的内容

- GitHub Token、API Key、Cookie、密码或私钥
- 真实玩家账号、设备标识和未脱敏用户数据
- 商业项目尚未公开的策划案、角色设定和运营数据
- 未获授权的品牌素材、完整游戏截图和源文件
- 来源不明的字体、图标、音乐或角色资产

提交前检查：

```bash
git status --short
git diff --cached
```

发现敏感信息时不要提交，也不要只靠删除最新文件来处理已经推送的历史。

## 参考图使用原则

技能应抽象：

- 色彩与对比
- 材质、光向和阴影
- 信息层级和布局密度
- 圆角、描边和图标语法
- 交互状态和反馈模式

技能不应复刻：

- 受保护角色的独特造型
- 商标、Logo 和品牌文字
- 完整页面构图和可识别商业素材
- 其他项目的原始切图

无法确认授权时，使用原创占位角色、通用题材语言和无品牌文案。

## 生成图片审查

批准资源前检查：

- 是否意外生成现有 IP 角色或 Logo
- 是否包含乱码、错误价格或误导信息
- 是否包含不合适人物、符号或敏感内容
- 文件元数据是否泄露本地路径、账号或工具信息
- 背景移除是否产生脏边或残留原图

生成结果不能因为“只是 AI 生成”而自动视为可商用。

## Manifest 与来源

每个资源应记录：

- 生成或导入状态
- 提示词路径
- 实际文件路径和尺寸
- 源页面或源资源
- 批准状态
- 必要的来源、许可证和限制说明

第三方资源的许可证应单独保存，不能只在聊天中说明。

## GitHub 协作

- Issue 和 PR 中使用最小可公开复现，不上传完整商业素材。
- 截图前遮盖账号、项目名、内部 URL 和数值。
- Actions 日志不得打印环境变量或 Token。
- Fork 公开仓库前确认示例不包含公司资产。

## 报告安全问题

不要在公开 Issue 中发布有效凭据或可利用的敏感信息。先撤销泄露凭据，再通过仓库所有者可用的私密联系方式报告。

本仓库当前不处理网络请求、账号系统或玩家数据；主要风险来自输入素材、生成资源和 Git 历史中的敏感内容。
