# Text-free shop component sheet

Generate one transparent component board for a western-cartoon survival shop.

Include exactly:

1. Purchase button base: normal.
2. Purchase button base: hover.
3. Purchase button base: pressed.
4. Shop upgrade progress base.
5. Parchment product card.
6. Category tab base: active.
7. Category tab base: inactive.
8. Gold currency icon.
9. Red sale badge base.

Requirements:

- Transparent background.
- Every element is complete, isolated, and separated by generous empty space.
- No words, letters, prices, numbers, labels, watermarks, or text residue.
- No grid lines, arrows, captions, or item numbering.
- Keep shadows and highlights inside each element boundary.
- Use green painted wood, parchment, warm gold, red accents, and consistent top-left lighting.
- Button and progress bases must preserve corners suitable for reviewed 9-slice margins.
