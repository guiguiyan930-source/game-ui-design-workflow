# UI 研究记录

## 研究范围

- 项目 ID：`factory-v2-shop`
- 分析对象：公开 ChatGPT 分享对话，以及用户后续提供的三张案例图片
- 研究目标：把页面生成优化为 Token → 组件 → 语义切图 → Atlas → 引擎清单流水线

## 参考图视觉抽象

- 色彩与对比：绿色主操作、羊皮纸次表面、深灰背景、红色风险、金色奖励
- 材质与纹理：彩绘木材、羊皮纸、搪瓷、磨损金属
- 光源与阴影：左上柔光，8px 软阴影
- 圆角、描边与厚度：18px 卡片圆角、2–8px 描边
- 构图密度：顶部资源、左侧分类、中央 3×2 商品、右侧角色、底部成长
- 图标视角：正视、粗轮廓、适合小尺寸识别
- 字体气质：粗体友好；最终文字由引擎排版

## 可复用模式

- 导航模式：左侧竖向分类，激活态绿色
- 卡片模式：木框和羊皮纸商品容器
- 反馈模式：按钮 normal / hover / pressed，货币不足与售罄独立状态
- 信息层级：资源 > 商品 > 购买 > 商店成长

## 玩家旅程与核心循环

1. 首次进入：看到资源余额和默认商品分类
2. 准备：切换分类并检查库存
3. 核心玩法：购买商品或升级商店
4. 结算与成长：商店经验推进并解锁奖励
5. 日常回流：刷新商品并继续下一轮

## 风险与约束

- 版权与品牌：不使用 PVZ 角色、商标或完整构图
- 文字生成：组件合图禁止文字；页面文字可后期合成
- 平台安全区：桌面端四周保留 24–30px
- 复杂度与开发成本：自动视觉检测和原生引擎插件不属于当前实现

## 决策

- 采用：确定性语义 mapping、人工审核 9-slice、无旋转 Atlas、引擎 JSON 清单
- 拒绝：把 Grounding DINO、SAM2、自动去字和原生工程导出描述为已完成
- 原因：当前仓库可验证的是规则、图片元数据与确定性脚本，不包含大型模型和引擎 SDK
