# UI 项目规格

## 项目定位

- 项目 ID：`factory-v2-shop`
- 游戏名称：Survivor Shop（案例名）
- 游戏类型：2D 欧美卡通生存 Roguelike
- 核心玩法：战斗后购买资源、升级商店并准备下一轮
- 目标平台：桌面端，Godot / Unity / Cocos 交付
- 画面比例：16:9，1920×1080
- 目标用户：喜欢轻度策略和独立游戏的玩家
- 文案语言：英文页面示例；组件素材无文字

## 输入资料

- 参考图片：`references/component-breakdown-board.png`、`references/shop-screen.png`、`references/ui-system-board.png`
- 现有页面：用户提供的案例参考图，以及根据公开对话描述独立重构的商店示意图
- 品牌或版权限制：只抽象欧美卡通、木质和绿色风格，不复刻受保护角色

## 用户故事

### US-01

作为一名玩家，我希望快速筛选商品并确认价格与库存，从而在下一轮战斗前完成准备。

验收场景：

1. Given 玩家进入商店，When 切换分类，Then 中央 3×2 商品网格显示对应库存。
2. Given 货币不足，When 点击购买，Then 按钮和价格区显示明确反馈。

## 范围

### 包含

- UI Token、商店页面契约和重构视觉稿
- 无文字组件雪碧图、语义 PNG、9-slice 元数据、Atlas 与引擎 JSON

### 不包含

- 自动视觉检测、自动去字修复、自动九宫格推断
- 原生 `.tres`、`.tscn`、Unity SpriteAtlas 或 Cocos 工程文件

## 视觉目标

- 情绪：温暖、轻松、末日中的生存韧性
- 风格关键词：western-cartoon、roguelike、painted-wood、parchment
- 识别性目标：绿色购买操作、羊皮纸商品卡和木质分类栏
- 可读性目标：主购买操作三秒内可定位，资源与进度区不竞争

## 页面范围

- 首个生成页面：`shop`
- 必须延展的系统：组件语义映射、9-slice、Atlas、引擎交付
- 可选系统：商品详情弹窗、购买确认、刷新商店
