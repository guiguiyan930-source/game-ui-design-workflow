# 首页背景

## 来源与用途

来源页面 `home`，用作无控件的月宫首页底图。

## 尺寸和状态

1080×1920，默认状态，不透明背景。

## 必须继承的契约字段

午夜蓝背景、白玉月宫、低对比云纹、左上柔光、中心月轮。

## 图像生成提示词

生成一个独立的竖屏游戏 UI 场景背景，9:16，午夜蓝月宫，巨大柔和月轮位于中心上方，白玉台阶与远处宫阙，低对比云纹和少量青蓝雾气，左上柔光，深蓝鎏金国风神话气质。画面中间和底部预留 UI 与角色叠放空间。完整场景底图，无角色、无按钮、无卡片、无图标、无导航、无任何文字或商标，边缘自然可延展，高清。

## 反向限制

不要 UI 控件、文字、人物、红色主调、强烈写实材质、错误透视、低清晰度。

## 验收记录

背景允许不透明；中心留白必须足以叠放角色与 CTA。
