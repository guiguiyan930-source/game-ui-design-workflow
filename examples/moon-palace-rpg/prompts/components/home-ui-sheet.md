# 首页 UI 组件雪碧图

## 用途

作为自动切图的中间产物，包含六个圆形导航图标和三个横向按钮状态。

## 生成规则

- 透明背景。
- 所有元素完整、互不接触并留有明显间距。
- 图标使用深蓝、鎏金、青蓝和白玉视觉语言。
- 三个按钮保持相同轮廓，分别表示默认、按下和禁用状态。
- 不要文字、编号、网格线、水印和说明箭头。
- 阴影与发光不能跨到相邻元素。

## 后处理

使用 `game-ui-sprite-sheet-splitter` 或 `scripts/split_sprite_sheet.py` 导出独立透明 PNG，并打包 ZIP。雪碧图本身不作为最终组件交付。
