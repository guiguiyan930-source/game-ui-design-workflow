# 主按钮

## 来源与用途

来源页面 `home`，用于继续主线、确认和领取等最高优先级操作。

## 尺寸和状态

640×192，示例生成默认状态；按下和禁用状态沿用同一轮廓。

## 必须继承的契约字段

鎏金主色、白玉内层、青蓝内缘、28px 以内圆角、左上高光、短距离深蓝投影。

## 图像生成提示词

生成一个独立的游戏 UI 主按钮组件素材，横向宽按钮，约 10:3 比例。深蓝鎏金国风神话风格，磨砂白玉按钮面，完整的拉丝金属包边，青蓝色细内缘，左上白玉高光，底部短距离深蓝投影，真实可点击，轮廓对称，中心留出宽阔空白排字区域。透明背景，不要文字，不要图标，边缘干净，中心构图，高清，适合后期合成与开发切图，不要生成完整页面。

## 反向限制

不要文字、乱码、其他组件、矩形背景块、脏边、裁切、错误透视、红色、塑料质感和不对称边框。

## 验收记录

正式交付需检查 alpha 通道；不具备透明输出的工具应保留 `pending-generation`。
