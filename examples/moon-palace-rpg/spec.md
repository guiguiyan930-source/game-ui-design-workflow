# UI 项目规格

## 项目定位

- 项目 ID：`moon-palace-rpg`
- 游戏名称：月宫列传
- 游戏类型：国风神话卡牌 RPG
- 核心玩法：六人编队、回合战斗、角色养成与月相羁绊
- 目标平台：手机竖屏
- 画面比例：9:16
- 目标用户：偏好东方幻想与轻策略养成的 18–35 岁玩家
- 文案语言：简体中文

## 输入资料

- 参考图片：无外部素材；本示例从“深蓝鎏金、月宫、玉石”关键词建立原创视觉
- 现有页面：无
- 品牌或版权限制：不使用现有神话游戏商标、角色造型或完整构图

## 用户故事

### US-01

作为一名回流玩家，我希望在首页立即看到当前阵容、体力与主线入口，从而在三秒内继续核心玩法。

验收场景：

1. Given 玩家进入首页，When 页面完成加载，Then 主线 CTA、资源状态与底部导航清晰可见。
2. Given 活动已过期，When 玩家查看活动入口，Then 入口显示过期状态且不遮挡主线。

## 范围

### 包含

- UI 规范、首页与编队页屏幕契约
- 首页视觉提示词与可复现资源记录
- 首页背景和主按钮组件拆解示例

### 不包含

- 战斗数值、服务端接口与可运行客户端
- 其他页面的最终视觉稿

## 视觉目标

- 情绪：静谧、尊贵、神秘但不压抑
- 风格关键词：深蓝、鎏金、白玉、云纹、月轮
- 识别性目标：月轮主视觉与玉石鎏金交互控件形成项目识别
- 可读性目标：文字区使用低细节深蓝底，主操作达到强对比

## 页面范围

- 首个生成页面：首页
- 必须延展的系统：首页、编队、关卡、战斗 HUD、结算、角色、背包
- 可选系统：召唤、活动中心、公会
