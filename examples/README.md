# 示例索引

## 完整项目

- [云阙列传（国风卡牌 RPG）](guofeng-card-rpg/README.md)：**主案例**。含生成第 1 步（GDD/PRD/交互）、六页视觉、语义切图、Atlas 与 Godot/Unity/Cocos JSON。
- [月宫列传](moon-palace-rpg/README.md)：早期完整可校验示例，仍供分阶段操作示例引用。
- [Game UI Factory v2 商店](factory-v2-shop/README.md)：欧美卡通商店 Token、9-slice、Atlas 与引擎 JSON 专项案例。

## 分阶段操作示例

- [UI 风格切换](style-switch/README.md)：保持页面结构不变，对比、选择并冻结新的视觉方向。
- [UI 页面延展](screen-extension/README.md)：从一个首页建立首发屏幕地图，再逐页生成。
- [UI 组件包拆解](component-pack/README.md)：从已批准页面拆出背景、按钮、导航和资源图标。
- [雪碧图拆分与 PNG 打包](sprite-sheet-splitting/README.md)：自动切出单元素透明 PNG、生成 manifest 和 ZIP。

分阶段示例仍可使用 `moon-palace-rpg` 作为输入；新项目请优先参考 `guofeng-card-rpg`。
